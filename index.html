How the Pod Works 4 stages
  1. Plan →

    1. Repo Audit & /plan Gate

    Maps repository structure, sets parallel file guardrails, and aligns on a human-approved /plan before edits begin.

  2. Execute →

    2. Parallel Builder & Research Pods

    Dispatches scoped subagents concurrently—pairing frontend engineering with live Deep Research synthesis without file conflicts.

  3. Verify →

    3. Isolated Browser QA Verification

    Checks layout, dark/light tokens, interactive filters, and responsive fidelity at desktop (1440px) and mobile (390px) viewports.

  4. Ship ✓

    4. Git Checkpoint & Deploy

    Validates links, accessibility, and zero-build static assets before checkpointing clean commits to GitHub Pages.
